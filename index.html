ⓘHow verification works. Every requirement shown is labelled Established (long-standing, confirm current text), Verify (subject to amendment or annual update), or Unverified (must be confirmed against primary sources). Content not drawn from BMA or legislation carries a visible source label. These labels describe the knowledge base, not a guarantee of accuracy. Confirm source text and applicability before use.

About this project

Created by Daniel Khisa, this educational portfolio project demonstrates how regulatory research can be organised into practical, inspectable workflows: an entity questionnaire, dated source references, filing estimates, and correspondence starting points.

The navigator uses vanilla HTML, CSS and JavaScript with a versioned local knowledge base. There is no account, subscription, paid AI service, analytics, backend or build step. Assessment bookmarks and knowledge-base updates stay in your browser unless you export them.

Scope: insurance content is more detailed; other sectors have limited framework coverage. SBA refers to the Scenario-Based Approach used in insurance valuation. This project does not provide quizzes, professional advice, regulatory approval or a complete compliance calendar.

Independent demonstration: not issued, endorsed or approved by the Bermuda Monetary Authority. The knowledge base is pending legal review. Confirm the current source text and your entity's circumstances before relying on any output.

Privacy & local storage

This free edition uses a local knowledge base. It does not send assessment inputs to an AI service, request an API key, or use analytics. External source links open third-party sites when you choose them.

Saved assessment inputs and imported updates remain in this browser. Browser data can be lost or read by someone with access to this device. Use initials or a pseudonym and keep confidential entity information out of this demonstration. Exports contain the saved information.

If you used an earlier edition, its API key may still be stored here. This edition does not read or use it. You can remove it explicitly below.

Save this assessment

Saves the wizard inputs, mode, and knowledge-base version to this browser's localStorage as an input bookmark, not as a frozen report. Browser-local storage is per-device and per-browser: it is not a controlled compliance system of record.
